Memory Scope

memory Retained Context
  • work Work Patterns: Frequent collaborators, active projects, and standard meeting schedules.
  • tune Preferences: UI layouts, notification thresholds, and ambient lighting states.
  • edit_document Communication Style: Tone, typical sign-offs, and formatting preferences in drafts.
delete_sweep Discarded Context
  • error Errors: Typos, deleted drafts, and abandoned queries.
  • block Failed Attempts: Unsuccessful logins or rejected authentication requests.
  • timer Ephemeral Data: Clipboard history older than 1 hour and temporary session tokens.
