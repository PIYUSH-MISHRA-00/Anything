## Before opening an issue

Check the [FAQ](/guide/faq), then confirm your checkout is healthy:

```bash
flutter test test/r46_architectural_integrity_certification_test.dart
```

If those 102 invariants fail on a clean checkout, **that is itself the bug** —
please report it.

## Already known

You do not need to report these:

| Issue | Status |
|---|---|
| No published Play Store build | In progress |
| Never verified on a physical device | Next milestone |
| `ProviderRequired` with no AI key | Expected — add a key in Settings |
| A test occasionally fails in a full run and passes on re-run | **G-40**, unresolved |
| Accessibility is minimal | Known; [help welcome](/community/contributing) |
| No localisation | Known; [help welcome](/community/contributing) |

## Response expectations

This is a small project with one maintainer. Issues and PRs are read, but there
is no SLA. Security reports get priority over everything else.
