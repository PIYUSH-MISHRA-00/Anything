# features/preferences/

Settings and preferences: user configuration and app settings.

## What belongs here

- Settings screens and pages
- Preference toggles and inputs
- Theme selection UI
- Account and profile settings

## What does NOT belong here

- Core configuration model (use `core/config/`)
- Theme implementation (use `design_system/theme/`)
- Feature-specific settings (use respective `features/` folders)

## Key interfaces

- `PreferencesScreen`
- `SettingsPage`
- `ThemeSelector`
