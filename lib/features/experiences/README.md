# features/experiences/

Experience library: browse, manage, and interact with experiences.

## What belongs here

- Experience list/grid views
- Experience detail screens
- Experience creation and editing UI
- Experience search and filtering

## What does NOT belong here

- Experience execution logic (use `runtime/`)
- Experience storage (use `storage/`)
- Home/intent surface (use `features/home/`)

## Key interfaces

- `ExperienceLibraryScreen`
- `ExperienceDetailView`
- `ExperienceCard`
