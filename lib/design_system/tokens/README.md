# design_system/tokens/

Design tokens: the atomic visual primitives of the design system.

## What belongs here

- Color tokens and palettes
- Typography scale and font definitions
- Spacing and sizing scale
- Border radii tokens
- Shadow and elevation tokens
- Animation duration and easing tokens

## What does NOT belong here

- Widget implementations (use `design_system/components/`)
- ThemeData configuration (use `design_system/theme/`)
- Feature-specific styling (use `features/`)

## Key interfaces

- `ColorTokens`
- `TypographyTokens`
- `SpacingTokens`
- `RadiusTokens`
- `ShadowTokens`
