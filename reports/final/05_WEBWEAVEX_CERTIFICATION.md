# 05 — WebWeaveX Certification

## WHAT IT DOES

- Knowledge acquisition via adapter `lib/knowledge/webweavex_adapter.dart`
- Bounded fetch, HTML extraction, repository/document IR, deterministic serialization, runtime normalization for knowledge surfaces

## WHAT IT DOES NOT

- Not weather (`DataProviderRegistry` / Open-Meteo)
- Not news (`DataProviderRegistry` / Google News RSS)
- Not Kaalka / protection crypto
- Not runtime graph, memory fabric, or workflow runtime ownership

## Failure rule

A WebWeaveX / knowledge failure **must not** degrade into a Wikipedia (or other encyclopedia) substitute for weather/news or app generation. Weather/news labels on device confirm provider paths.
