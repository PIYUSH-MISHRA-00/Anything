# 20 — Owner Manual Acceptance

Owner checklist before declaring store/public launch complete:

- [ ] Confirm installed APK SHA-256 matches `14_BUILD_REPORT.md` / `19_HASHES.txt`
- [ ] Create stopwatch — Start / Pause / Resume / Reset labels fully visible
- [ ] Create scientific calculator — scientific mode functions present
- [ ] Weather for a city — Open-Meteo result renders
- [ ] News for a locale — Google News RSS result renders
- [ ] Task or expense CRUD — add item; force-stop; reopen persists
- [ ] Protect an app with Kaalka; unlock with current time; reopen
- [ ] Export to `Downloads/Anything/*.anything`
- [ ] Delete exported app; Import via picker; reopen works
- [ ] Enable GitHub Pages (resolve 422 if needed)
- [ ] Play Console: signing, listing, privacy policy, screenshots, submit AAB
- [ ] Sign off: PRODUCTION COMPLETE — OWNER ACCEPTED (date / name)
