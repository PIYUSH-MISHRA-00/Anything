# Assets Directory

This directory contains all visual, audio, and font assets for the project.

## Structure

- **branding/**: Logos, brand marks, and visual identity assets
- **icons/**: App icons (SVG preferred), feature icons, UI icons
- **illustrations/**: Custom artwork, onboarding illustrations, decorative graphics
- **images/**: General image assets (including app_icon.png)
- **animations/**: Lottie files, .json animations, .gif animated assets
- **audio/**: Sound effects, voice prompts, UI feedback audio
- **fonts/**: Custom font files (.ttf, .otf, .woff2)

## Guidelines

- Place assets in the appropriate subdirectory based on their type
- SVG format is preferred for icons and scalable graphics
- Keep original source files (e.g., .ai, .psd, .sketch) in a separate design directory
- Do not place design screenshots (screen.png, code.html) in any asset directory
